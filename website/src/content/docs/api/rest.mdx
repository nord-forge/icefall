The Icefall REST API is served under `/api/v1`. Start with the
[API overview](/api/overview/) for the base URL, authentication, the required
`X-Icefall-Request` header on writes, the shared error format, pagination, and
rate limits.

## Resource reference

| Resource | What it covers |
|----------|----------------|
| [Apps](/api/apps/) | Create and configure apps, control containers, scale, instances, load balancing |
| [Deploys](/api/deploys/) | Trigger, list, cancel, roll back, approve; deploy events and analytics |
| [Databases](/api/databases/) | Provision databases, link to apps, backups, restore, SSL |
| [Domains](/api/domains/) | Attach custom domains and verify DNS |
| [Environment variables](/api/env-vars/) | Scoped app env vars, bulk import, shared and project-environment variables |
| [Servers](/api/servers/) | Enroll and manage servers, metrics, forecasts, agent updates |
| [Auth](/api/auth/) | Login, sessions, first-run setup, two-factor authentication |
| [Users](/api/users/) | User management, roles, invites, account settings, OAuth identities |
| [API tokens](/api/tokens/) | Create, list, and revoke API tokens |
| [Notifications](/api/notifications/) | Channels, per-app rules, outbound webhook endpoints |
| [Settings](/api/settings/) | Instance settings, container runtime, base domain, registration |
| [Webhooks](/api/webhooks/) | Inbound GitHub and GitLab webhooks, GitHub App integration |
| [MCP server](/api/mcp/) | Tools, resources, and prompts for AI assistants |

## OpenAPI

A machine-readable OpenAPI 3.1 document is served, unauthenticated, at
`/api/v1/openapi.json`.
