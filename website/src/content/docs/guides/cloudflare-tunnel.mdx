<Aside type="caution" title="Planned feature">
Cloudflare Tunnel support is planned but not yet available. The settings surface
for a tunnel exists in the dashboard, but the backend integration that connects
your instance to Cloudflare is not implemented yet. This page will be expanded
into a full how-to once the feature ships.
</Aside>

## What it will do

A Cloudflare Tunnel lets Icefall serve apps without a public IP or open inbound
ports. Outbound connections from your server establish the tunnel, and Cloudflare
routes public traffic to your apps over it — useful for hosts behind NAT, home
labs, and locked-down networks.

## In the meantime

Until tunnel support ships, expose apps the standard way:

- Add a [custom domain](/guides/custom-domain) and let Icefall obtain a
  certificate.
- For wildcard subdomains, see [wildcard domains](/guides/wildcard-domain).

If you already run `cloudflared` yourself, you can point a tunnel at the host port
Icefall publishes for an app, independently of Icefall.
