Time to complete: about 15 minutes.

Icefall runs on Podman as an alternative to Docker. Podman is API-compatible with
the Docker socket interface Icefall uses, so day-to-day operation is the same.
This guide installs Podman and points a fresh Icefall install at it.

## Prerequisites

- A Linux host with `systemd`.
- Podman 4.0 or newer (Icefall requires at least 4.0).
- Root or sudo access.

## Choose the runtime at install time

<Steps>

1. Tell the installer to use Podman with the runtime flag or environment
   variable:

   ```bash
   ICEFALL_RUNTIME=podman ./install.sh
   ```

   or

   ```bash
   ./install.sh --runtime=podman
   ```

   The default, `auto`, detects a running Podman 4.0+ and otherwise falls back to
   Docker.

2. The installer installs Podman if it is missing (apt, dnf, or apk) and enables
   the Podman socket via `systemctl enable --now podman.socket`.

</Steps>

## Verify the socket

Icefall talks to Podman over its socket. The common paths are:

- Rootful: `/run/podman/podman.sock`
- Rootless: `/run/user/<uid>/podman/podman.sock`

Confirm the socket is active:

```bash
systemctl is-active podman.socket
podman info
```

## Confirm Icefall's runtime

The selected runtime is written to `/etc/icefall/config.toml` under the
`runtime` key, and a re-install never flips it. You can also override the runtime
for the process with the `ICEFALL_RUNTIME` environment variable
(`docker`, `podman`, or `auto`).

## Networking note

On Podman, inter-container name resolution uses the netavark and aardvark-dns
stack. If your apps resolve each other by name, install `aardvark-dns`. See
[Docker vs Podman differences](/reference/podman-differences) for the full list
of behavioral differences.

## Verify

<Steps>

1. Start Icefall and sign in.

2. Deploy a small app and confirm the build and run succeed on Podman.

3. Check the app's published ports are reachable.

</Steps>

## Troubleshooting

- **Podman too old**: Icefall requires 4.0+. Upgrade Podman, then re-run setup.
- **Socket not found**: enable it with `systemctl enable --now podman.socket`.
- See [Podman troubleshooting](/guides/podman-troubleshooting) for socket,
  networking, exec, and stats issues.
