Time to complete: about 5 minutes.

The log viewer streams an app's output in real time and lets you filter by text
and level. It is the fastest way to follow a deploy or chase down an error.

## Prerequisites

- A deployed app producing logs.

## Open and follow logs

<Steps>

1. Open the app and go to the **Logs** tab.

2. New lines stream in automatically. Auto-scroll keeps the newest line in view;
   scrolling up pauses it so you can read, and returning to the bottom resumes
   it.

</Steps>

## Filter

<Steps>

1. Type in the **search** box to keep only lines that contain your text. The
   match is case-insensitive.

2. Use the **level** filter to show only `INFO`, `WARN`, or `ERROR`, or `all`.

3. Combine search and level to narrow quickly, for example `timeout` at level
   `ERROR`.

</Steps>

## Download

Use **Download** to save the current logs as a `.txt` file for sharing or
offline analysis. **Clear** empties the on-screen buffer without affecting stored
logs.

## Query the API directly

You can also pull logs over the API:

```bash
curl -H "Authorization: Bearer icefall_your_token_here" \
  "https://your-icefall-instance.com/api/v1/apps/<app-id>/logs?search=error&limit=200"
```

Supported query parameters include `search`, `stream`, and `limit` (default 200).

## Troubleshooting

- **No new lines**: confirm the app is running and writing to stdout/stderr.
- **Missing older lines**: the viewer keeps a rolling buffer. Use **Download** or
  a [log drain](/guides/log-drains) to retain history.
